How it works

files.dliu.com hosts files that anyone can download and that other dliu.com sites can link to or embed. There are no servers: files sit in S3, CloudFront delivers them, and a small Lambda function runs only when the owner signs in or changes something.

Running costs

Everything is billed per use. With nobody downloading, the only charge is storing the files in S3.

Security

Anyone can download; only the owner, signed in with Microsoft, can upload, move or delete.

How this site is tested

status.dliu.com checks files.dliu.com every 15 minutes as an anonymous guest: it only requests public URLs and never signs in. This section explains what it checks and what “down” means for a visitor. The full technical version is at /docs/health.md.

API

Other dliu.com sites, tools and AI agents can list and change files through the managed API. It uses Microsoft tokens from auth.dliu.com, not the website sign-in. This section shows what it can do with diagrams and tables; the full machine-readable reference is at /docs/api.md.
