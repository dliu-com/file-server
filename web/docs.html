How it works

files.dliu.com hosts files that anyone can download and that other dliu.com sites can link to or embed. There are no servers: files sit in S3, CloudFront delivers them, and a small Lambda function runs only when the owner signs in or changes something.

Running costs

Everything is billed per use. With nobody downloading, the only charge is storing the files in S3.

Security

Anyone can download; only the owner, signed in with Microsoft, can upload, move or delete.
